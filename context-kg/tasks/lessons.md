# VOHU Evals 经验记录

- `context-kg` 只沉淀评测器自身的稳定实现知识；实验流水、环境状态、账号操作、跨仓库部署过程和外部宣传材料不得进入长期知识库。
- `targets/` 属于本地运行输入，不得提交真实 allowlist 或 composition；默认离线验证不能依赖该目录存在。
- 文档示例使用抽象占位符，不写真实账号、服务地址、凭据、执行标识、运行标识、提交标识、费用或逐题内容。
- Benchmark 的题库、评测器、版本、校验值与发布状态以代码 manifest 为权威；知识库不复制容易漂移的具体值。
- 被测对象始终是经 APIGO Gateway 调用的 VOHU；外部模型不是本项目的运行目标。
- 真实运行与默认测试必须隔离，任何可能产生费用的动作都需要显式执行和预算确认。
- 固定分母保留系统失败和无效输出；不得只用成功完成样本重算成绩。
- 原始题库、回答、账本与未批准报告属于本地运行工件，不进入 Git 或长期知识库。
- 报告叙事不得自行计算指标；所有数字和发布状态必须来自可验证 evidence。
